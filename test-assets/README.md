# Test Assets

This directory contains sample menu PDFs for testing the Menu Chef application.

## Creating Test PDFs

To test the application, you can:

1. **Use existing restaurant menu PDFs** - Download menu PDFs from restaurant websites
2. **Create your own** - Use any PDF editor or word processor to create a simple menu
3. **Use online samples** - Search for "sample restaurant menu PDF" online

## Recommended Test Format

For best results, test PDFs should have:
- Clear text (not scanned images)
- Prices with currency symbols ($, €, £, ¥)
- Section headers (e.g., "Appetizers", "Main Courses")
- Item names and descriptions
- Simple layout (single column works best)

## Quick Test

If you don't have a menu PDF handy, you can:
1. Copy the example menu structure above
2. Paste it into a Google Doc or Word document
3. Format it nicely (adjust fonts, spacing)
4. Export as PDF
5. Upload to Menu Chef

## Notes

- The application works best with text-based PDFs
- Scanned PDFs (images) may not work properly
- Complex layouts may not be perfectly preserved
- Start with simple menus to test the core functionality
